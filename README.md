# 砚台 · ST伴侣 (`st-mate`)

![Version](https://img.shields.io/badge/version-0.3.0-d4b98c)

> **定位**：可逆夺舍式 SillyTavern 极简伴侣总台 —— 全模块自由插拔、零美化覆盖、静默流畅加速、一键无损切回原生酒馆。

---

## 安装与更新方式

1. 打开酒馆右上角 **扩展（Extensions）** -> **安装扩展（Install extension）**
2. 粘贴以下 GitHub 仓库地址并点击安装：
   ```text
   https://github.com/ayan-atelier/st-mate
   ```
3. 安装后刷新网页即可生效；后续可在酒馆扩展管理内直接点击检查更新（已支持 `auto_update`）。

---

## 核心功能速览（v0.3.0）

1. **⚡ 流畅渲染引擎（后台静默加速 · 默认开启）**
   - **底图离屏压缩与 `IndexedDB` 缓存**：角色卡大图自动压缩缓存为轻量纹理，松手静态烘焙柔焦，消除滚动逐帧高斯模糊重算；
   - **百楼长对话离屏自动休眠**：保持最新活跃楼层实时响应，上方历史楼层自动启用 `content-visibility: auto` 与离屏动画暂停；
   - **闭合抽屉断电 & 手机端减负**：隔离未展开的原生抽屉渲染，移动端窄屏自动卸除多层重叠高耗电毛玻璃，弹起软键盘时锁定底图高度防跳动。

2. **Aa 页面排版与背景抽屉（与酒馆主栏等宽下拉 · 100% 兼容各类美化主题）**
   - **文字排版**：`字号`（`A− / +A` 与无级拖动）、`边距`（`小− / +大`）、`首行`（`顶格 / 缩进`）、`行距`（`紧− / +松`），未调整项零样式注入；
   - **背景图**：`角色图`（自动取当前卡面内嵌至阅读主栏底层）· `自定义`（支持本地图库自由拖拽缩放裁切上传 + 图床直链）· `原版`，配实时 `亮度` 与 `清晰度` 滑杆；
   - **其它实用开关**：`字体切换`（宋 / 黑 / 楷 / 自定义 `woff2` 或 ZeoSeven `result.css`）、`隐去头像`、`无框书页`，以及双向直连酒馆底层的 **`右滑重Roll·开启/关闭`**（彻底解决手机滑屏误触重Roll痛点）。

3. **沉浸双态顶栏 & 全屏纯享阅读**
   - 对话页支持 `RP态` 与 `阅读态` 切换，轻触正文空白处即可零重排丝滑隐去顶底栏进入纯享阅读；
   - 原生预设/API、角色/世界书抽屉顶部内嵌互切胶囊桥；
   - 随时可点首页「原生酒馆」或设置中心总开关一键无损退回纯原版酒馆。
