# 砚台 · SillyTavern 伴侣 (`st-mate`)

![Version](https://img.shields.io/badge/version-0.8.8-d4b98c)

> **定位**：可逆夺舍式 SillyTavern 极简伴侣总台 —— 全模块自由插拔、零美化覆盖、静默流畅加速、一键无损切回原生酒馆。

---

## 安装与更新方式

1. 打开酒馆右上角 **扩展（Extensions）** -> **安装扩展（Install extension）**
2. 粘贴以下 GitHub 仓库地址并点击安装：
   ```text
   https://github.com/ayan-atelier/st-mate
   ```
3. 安装后刷新网页即可生效；后续可在酒馆扩展管理内直接点击检查更新（已支持 `auto_update`，移动端刷新自动附加版本参数破除旧样式缓存）。

## 核心功能全景（v0.8.8）

### 0. 书架首页「万能自动识别分流导入」（新手零门槛混传）
- 点击书架统计栏旁的导入图标（或输入 `/stmate import`），支持**一次全选混着导入**从社区帖子下载的整套文件，按文件头字节与 JSON 结构指纹自动分流到位：
  - **角色卡**（`.png` / `.charx` / `.byaf` / V1·V2·V3 `.json`）→ 自动导入书架并补齐移动端缺失 MIME；
  - **对话预设**（`.json`）→ 自动剥离外部反代/密钥残留后导入并切换启用；
  - **美化主题**（`.json`）→ 自动存入主题库并当场切换生效；
  - **世界书**（ST / NovelAI / Risu / Agnai `.json`）→ 自动导入并同步注册至内存 `world_names`；
  - **正则脚本**（单条或数组包 `.json`）→ 自动写入全局正则列表（同名同规则自动原地更新零重复堆积）；
  - **快速回复 & 酒馆助手脚本**（`.json`）→ 自动转交对应扩展导入。

### 1. 角色档案与世界书一体页（顶栏左上角 `[头像 + 角色名]` 下拉）
- **画册海报式角色主卡、未进卡角色名录、内联改名 & 一键换开场白**：
  - 电脑端左置 `3:4` 大幅高清竖版立绘并等高整合角色名、专属预设绑定、主世界书绑定与导出操作；手机竖屏顶部居中高清大立绘配柔暗同图虚化氛围底（支持点击全屏原图灯箱预览），导出前自动 flush 草稿落盘 **导出 PNG 角色卡 / JSON**；未进卡时点击原版顶栏角色图标自动呈现支持搜索与标签速览的伴侣「角色名录」；
  - 核心设定（角色设定描述、性格特征、场景与背景、作者注释、角色专属提示词、对话示例）默认折叠防剧透，展开编辑 100% 自动一致性双写 V1 顶层与 V2 `data.*`；
  - 支持主/备用开场白胶囊秒切预览、增删改，以及 **开局第 1 楼免删档一键无损切换开场白**（自动对齐酒馆 `AI_OUTPUT` 正则与 `{{user}}` / `{{char}}` 宏替换，保留前端美化卡片与翻页手势）。
- **永不假生效的世界书**：
  - **四源智能聚合**：自动汇总当前对话真正生效的全部世界书（`角色主书` / `角色附加书` / `当前聊天书` / `全局开启`，群聊模式额外识别活跃成员书），打开即定位当前生效书；
  - **双重防假生效护栏**：点开未启用世界书时顶部琥珀色强提醒并支持 **一键绑为当前角色主书 / 开启为全局世界书**；同时自动检测当前预设是否关闭了前后置「世界书」占位槽并提供一键修复；
  - **人话蓝绿灯 & 防串书自动保存**：直观区分蓝灯「一直生效」与绿灯「提到词触发」，内置 **绿灯未填触发词预警**、一键新建世界书（自动注册进宿主 `world_names` 当场生效）、中英文全半角逗号关键词解析及 300ms 锁死快照防串书自动落盘；
  - **全部书库批量清理 & 一键重导卡内书 & 脚本热同步**：支持在全部书库内单本二次确认删除、按书名搜索一键全选批量清理旧书、强制「重导卡内书」覆盖同名世界书，以及角色卡脚本切开场白时实时热同步世界书开关状态；书架删卡后自动跳过原生安全占位页无缝留驻书架。

### 2. 统一「伴侣助手」内核 + 预设馆伴侣助手（零干扰双通道 · 前后对比勾选 · 多步悔棋）
- **主/副双轨通道零污染请求**：默认零配置复用当前主对话 API，亦可在 API 工作台指定独立副通道站子卡片并直接下拉搜索选择高速轻量模型（如 Flash），直连静默补全，100% 零篡改当前主连接设置、主密钥与聊天记录；
- **全局预设感知与 7 类安全原子操作（含小剧场美化正则自动配齐）**：自动紧凑序列化当前预设参数、有序条目与预设正则（点名长条目自动提权至 8000 字免截断），支持新增防抢话/文风条目、改写润色（支持局部精准替换或增量追加）、冲突排查开关、权重顺序微调、清理冗余项、核心参数调节，以及**一键生成随预设携带的半透可折叠卡片美化正则与历史省流剥离正则（`upsert_regex`）**，内置系统占位槽 (`marker`) 防误删与 Markdown 缩进代码块自愈护栏；
- **修改前后对比卡片 & 多步快照撤回**：每次改动均展示可折叠「修改前 vs 修改后」正文对比，支持逐项自由勾选采纳；应用前自动拍下完整预设快照入栈（最多可退 10 步，跨预设撤回前自动 flush 保护当前未存修改）。

### 3. 预设馆工作台（顶栏 `[预设名 ▾]` 下拉）
- **全局默认预设 + 角色专属双向绑定**：支持按 `char:<avatar>` / `group:<id>` 稳定唯一键双向绑定预设（顶部一键绑定当前角色 + 预设行展开一对多角色卡批量勾选），切卡无感秒切且保护当前 API 站子连接不被覆盖；
- **常用预设 & 预设仓库高密度分流**：未激活预设单行清爽点选即切，低频管理动作按需展开，备用预设可一键收进「预设仓库」（绑了该预设的角色卡进卡依然自动秒切），支持批量导入自动脱敏、纯净导出、另存副本、无损重命名联动与防误删保护；
- **单行折叠核心参数 & 提示词条目一键复制/内联编辑**：核心生成参数默认折叠为单行状态摘要（点击展开上下文 1M/2M 高上限解锁、最大回复与温度调节），配合提示词条目实时搜索、大热区开关、**一键复制条目**（紧随原条目正下方生成副本并自动展开编辑，默认关闭防误发）、上下微调排序、内联改写与 350ms 防抖自动落盘。

### 4. API 与模型工作台（顶栏插头键下拉）
- **多站子卡片存切 & 渐进披露清爽排版**：覆盖兼容 OpenAI 各类站子、Vertex AI（Express API Key / Service Account JSON）、AI Studio、Claude、OpenRouter、DeepSeek 等全部 26 个聊天补全来源；站子胶囊自动换行展示纯净名称（支持自主指定默认主站置顶），日常切换态收束为单行摘要，低频连接与消息后处理按需展开；API Key 100% 存入酒馆原生加密保险箱 `secrets.json`，秒切站子自动轮换密钥且零触碰对话预设；
- **URL 补全 `/v1`、真实测活、常用收藏秒切 & 副通道模型下拉**：支持一键补全 `/v1`、无污染发送轻量测试请求测活、拉取并多词模糊搜索模型列表、加星固定常用模型胶囊；独立「副 API 通道」卡片支持选定已存站子后直接下拉搜索该站子模型列表或后台静默拉取模型。

### 5. Aa 页面排版与背景 + 双风格顶栏一键切换 + 底栏发图识图
- **双风格顶栏一键切换（伴侣顶栏 / 原版顶栏）与图标显隐自定义**：既可使用伴侣极简沉浸顶栏，也可一键切为「酒馆原版顶栏」100% 保留美化主题的原版胶囊顶栏颜值与全部原生图标（含「背景图」），并在下方提供折叠式「原版顶栏图标显示设置」供玩家自由勾选显隐；
- **底栏快捷发图与表情包（自动开启识图 + 防炸反代瘦身）**：聊天输入框右下角嵌入低调半透明的 `1.5px` 细线图片微标（零挤占两侧宽度，多行输入时前几排满宽、图标始终贴合最后一行最右；支持粘贴截图与动图表情包），选图自动帮玩家开启底层 `media_inlining` 让模型看懂画面，并将手机超大图无感压缩防 `413` 报错；
- **扩展面板置顶总台横幅与黄金排序**：拼图扩展面板最上方置顶「砚台 · ST伴侣」直达大卡片，并按「正则 -> 酒馆助手 -> 快速回复 -> 第三方插件」清爽排布，二十余项低频原生内置模块统一收进底部折叠夹；
- **文字排版、高清底图、三色护眼调色 & 轻触全屏纯享阅读**：支持字号、桌面/手机独立边距、首行顶格/缩进、行距，角色图/自定义裁切底图/图床直链，以及 **正文 · 对话 · 内心三色独立取色与浅色字/深色字快捷配比**（切角色背景图不再怕字看不清，同时智能保护角色卡内联状态栏配色）；阅读时轻点正文空白，顶栏与底栏零重排丝滑隐去。

### 6. 静默流畅渲染引擎（后台无感加速 · 默认开启）
- **底图离屏压缩与 `IndexedDB` LRU 缓存**：角色大图后台压缩并静态烘焙柔焦纹理，消除滚动时逐帧高斯模糊重算；
- **百楼长对话离屏自动休眠**：保持最新活跃楼层实时响应，屏幕外历史楼层自动启用 `content-visibility: auto` 与离屏动画暂停；
- **闭合抽屉断电 & 移动端减负**：隔离未展开的原生抽屉渲染，手机窄屏自动卸除多层重叠毛玻璃并在弹起软键盘时稳定锁定底图视口高度。

### 7. 砚台套件自动配齐、同门防冲突与安全模式逃生舱
- **新用户开箱一键配齐**：首次启用时自动检测并后台串行补齐《角色书架》《人设馆》《重Roll助手》《叙事记忆》（默认开启项即装即用，默认关闭项零拦截静默待命，均可在设置中心自由开关；若玩家后续主动卸载某子插件，刷新绝不强行重装）；
- **同门旧版防打架与版本水位线护航**：自动休眠已被伴侣整合替代的旧版独立《界面整理》（解除 DOM 重排与深度监听冲突），并对低于兼容水位线的配套组件提供一键升级；
- **安全模式与零隐私体检单**：极端多插件冲突时支持网址末尾附加 `?stm_safe=1` 挂起启动，并内置 `/stmate diag` 与设置中心「复制环境排障体检单」（不含任何 API 密钥与聊天隐私）。

## 快捷斜杠命令与无损回退

支持在聊天输入框直接通过 `/stmate` 快速呼出任意工作台：

| 指令 | 作用 |
| :--- | :--- |
| `/stmate` | 打开「ST伴侣设置中心」控制面板 |
| `/stmate import` | 呼出「万能自动分流导入」文件选择器（支持角色卡/预设/主题/世界书/正则混传） |
| `/stmate char` | 打开当前对话「角色档案」面板 |
| `/stmate world` | 打开「世界书」管理面板 |
| `/stmate preset` | 展开或收起「预设馆」工作台 |
| `/stmate assistant` | 直接展开预设馆并唤醒「伴侣预设助手」 |
| `/stmate api` | 展开或收起「API 与模型工作台」 |
| `/stmate reader` | 展开或收起「Aa 页面排版与背景」抽屉 |
| `/stmate topbar` | 在「伴侣极简顶栏」与「酒馆原版顶栏」之间一键切换 |
| `/stmate diag` | 一键复制零隐私「环境排障体检单」 |
| `/stmate toggle` | 在「ST伴侣沉浸界面」与「纯原生酒馆界面」之间一键无损切换 |

> **零绑架承诺**：所有子模块均支持独立开关，关闭任意模块将立即退回酒馆对应原生面板；点击设置中心或书架右上角的「切回原生酒馆」会自动落盘未存草稿并恢复 100% 原汁原味的 SillyTavern 顶栏与抽屉。
