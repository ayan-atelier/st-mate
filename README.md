# 砚台 · SillyTavern 伴侣 (`st-mate`)

![Version](https://img.shields.io/badge/version-0.9.15-d4b98c)

> **让 SillyTavern 更好看、更顺手、更丝滑的一站式体验优化插件。**
> 底层加速与防卡防烫引擎静默开启，**默认完整保留你的原版顶栏与美化主题**，不碰旧存档、全模块独立开关，随时一键无损退回原生酒馆。
> 桌面浏览器、手机浏览器、云酒馆与 TauriTavern（TT）全部通用。

---

## 安装与更新

1. 打开酒馆顶栏 **扩展程序（Extensions）** → **安装扩展程序（Install extension）**
2. 粘贴下方 GitHub 仓库地址并点击安装：
   ```text
   https://github.com/ayan-atelier/st-mate
   ```
3. 安装后刷新页面即可生效（首次进入会轻弹一次双页签使用导览，随时可在设置中心或输入 `/stmate guide` 重看）。
4. **更新与历史回退**：可在酒馆「管理扩展」直接更新，也可在 **伴侣设置 → 原生与设置 → 版本与更新** 中手动检查更新、升级到最新版或一键回退至历史稳定版本（切换前自动备份全部伴侣设置，角色卡与聊天存档保持原样）。

## 核心功能一览

### 1. 底层加速与防卡防烫引擎（默认静默开启）
- **百楼长对话不卡不烫**：分端自适应长对话渲染窗口（电脑端宽裕无感，手机端智能守护内存并温和平衡流式帧率），一键回顶秒达窗口首楼，滚出视野的前端卡自动休眠省电，且第 0 楼美化样式始终驻留不崩。
- **大卡库丝滑浏览**：配合书架高清 WebP 封面缓存与名录分批续载，几百张角色卡也能秒开不卡顿。
- **高清底图离线缓存与手机端减负**：角色底图后台自动压缩缓存，移动端卸除高耗电重叠毛玻璃并稳锁弹键盘时的视口高度。

### 2. 顶栏「T」（简化顶栏「Aa」）· 随手调排版、背景与对话样式
- **排版与无框书页**：实时调节字号（内置「汇文明朝」）、页宽、首行缩进、行距与无框阅读体验，桌面端与手机端边距独立记忆。
- **角色立绘一键设背景**：把当前角色立绘或自定义图片设为阅读底图，随手调节亮度与清晰度。
- **对话与内心重点字**：内置 8 套深/浅底「经典搭配」，可给正文、对话、内心单独调色，或加上半截荧光笔、细虚线、柔和波浪与柔雾底框，并支持轻触正文进入纯享全屏阅读。
- **双风格顶栏随时切换**：默认 100% 保留你原本的酒馆顶栏与美化样式（下方支持自由勾选图标显隐），也可按喜好切换为更简洁的伴侣顶栏。

### 3. 书架首页「万能混传」一键导入
- 点击角色书架顶部导入图标（或输入 `/stmate import`），把帖子下载的整套资源全选一起拖进去，自动识别并分流归位：
  - **角色卡**（`.png` / `.charx` / `.byaf` / `.json`）→ 导入书架
  - **对话预设**（`.json`）→ 自动脱敏导入并启用
  - **美化主题**（`.json`）→ 存入主题库并切换生效
  - **世界书 / 正则脚本 / 快速回复 / 酒馆助手脚本** → 自动分流到对应模块

### 4. 核心面板全面升级（预设 / API / 角色与世界书 / 人设馆）
- **预设与 API 彻底解绑**：支持全局默认预设与角色 ⇄ 预设双向自动绑定（切卡秒切且绝不覆盖 API 连接），常用预设与备用仓库清爽分流，提示词条目支持搜索、一键复制、内联编辑与 AI 伴侣助手改写（改前改后对比勾选 ＋ 10 步撤回）。
- **多站子 API 工作台 & 全套共用「副 API」**：支持 26 个主流补全来源与酒馆原生加密保险箱存密钥、一键补全 `/v1`、测活与常用模型收藏；可单独指定高速轻量「副 API」，改预设、写人设、整理记忆全套共用，省钱快速且绝不污染主线对话。
- **永不假生效的世界书**：自动汇总当前对话真正生效的全部世界书，用蓝绿灯标清常驻/关键词触发状态，忘绑世界书或预设关闭占位槽时主动提醒并一键修复，支持批量清理旧书与强制重导卡内书。
- **角色档案与多封面轮换**：3:4 画册海报式档案、开局第 1 楼免删档一键切换开场白，还可在封面上传多张心仪立绘并开启「回首页随机轮换」。

### 5. 顺手的日常细节与配套增强
- **顺手的操作坐标**：左下角 `☰` 三横菜单人话重排（退出回书架、保存、存档管理、重写、续写一目了然）；每段对话右下角自带编辑、复制与 `···` 菜单（开新分支、保存此楼、对 AI 隐藏、删除）。
- **输入框右下角直接发表情包与图片**：点右下角低调图片图标或直接粘贴表情包，自动开启识图并智能压图防手机大图触发反代报错。
- **低频按钮隐藏（隐藏但不关停）**：在「伴侣设置 → 界面整理与低频收纳」中可按需折叠顶栏、三横、魔法棒与扩展页里的低频入口，点击展开查看，绝不关停后台插件。
- **记忆增强系统 & 重Roll回看加强**（均默认关闭零打扰，按需开启）：
  - **记忆增强系统**：开启后平时后台无感运行，每 3 轮自动总结剧情并生成独立世界书，长对话不忘细节且随时可点开微调；
  - **重Roll回看加强**：在楼层底部随时回看历史重Roll、加星收藏或分叉新支线。
- **内置授权美化《观月札记》**：在「伴侣设置 → 原生与设置」可一键切换 WWW 老师授权的《观月札记》（跟随系统 / 浅昼 · 日间 / 静夜 · 夜间），完整保留原版风格与人设馆兼容层。
- **主流社区插件与美化原生兼容**：开箱兼容博客小站（QuietRoom.org）、QR 助手、ST-QuickBar、ST-iPhonie、柏宝绘、兔子镜小剧场、织幕、墨提斯之镜等常见生态；极端多插件冲突时可在网址末尾加 `?stm_safe=1` 安全进场，并支持一键复制零隐私环境体检单。

## 常用斜杠指令

在聊天输入框输入 `/stmate` 即可快捷呼出任意面板：

| 指令 | 作用 |
| :--- | :--- |
| `/stmate` | 打开「SillyTavern 伴侣设置」面板 |
| `/stmate guide` | 重新打开「快速上手 / 进阶玩法」使用导览 |
| `/stmate import` | 呼出「万能混传」文件导入窗口 |
| `/stmate char` | 打开当前「角色档案」面板 |
| `/stmate world` | 打开「世界书」管理面板 |
| `/stmate preset` | 展开或收起「预设馆」工作台 |
| `/stmate assistant` | 直接唤起「伴侣预设助手」 |
| `/stmate api` | 展开或收起「API 与模型工作台」 |
| `/stmate reader` | 展开或收起「排版与背景」抽屉 |
| `/stmate topbar` | 一键切换「酒馆原版顶栏 / 伴侣极简顶栏」 |
| `/stmate diag` | 一键复制零隐私「环境排障体检单」 |
| `/stmate toggle` | 一键无损切换「伴侣界面 / 纯原生酒馆」 |

---

> **零绑架承诺**：所有功能模块均可随时单独开关，关闭即退回酒馆对应原生面板；在设置中心或书架首页点「切回原生酒馆」会自动保存草稿并恢复 100% 原汁原味的 SillyTavern 界面，你的角色卡、预设、世界书与聊天存档全程原样保留。
